# AI Dev Studio

Installers and signed updates for **AI Dev Studio** - an AI development studio for PC and Android, run by Claude Code as your lead.

## Install
Download `AIDevStudio-Setup-<version>.exe` from the [latest release](../../releases/latest) and run it.
Windows may warn about an unknown publisher: click "More info", then "Run anyway".

## Updates
Installed apps check this page's releases and update themselves. Every update is signed; the app only installs files signed with the AI Dev Studio publisher key, so a changed or broken file is refused.

This repository contains release files only, no source code.
